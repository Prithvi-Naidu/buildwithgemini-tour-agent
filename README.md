# 🏡 Airbnb TourCraft AI — 3D Video Tour Generation Agent

> Transform static 2D listing photos into photorealistic, steadycam 3D spatial room walkthrough video tours powered by **Google ADK**, **Gemini 2.5 Flash**, **Vertex AI Veo 3.1**, and **Google Cloud Text-to-Speech**.

## ✨ Features

- **🧠 Gemini 2.5 Flash Scene Sequencing**: Analyzes listing photos and structures them into a logical room-by-room walkthrough sequence (*Living Room -> Kitchen -> Master Bedroom -> Bathroom -> Outdoor Deck -> Hot Tub -> Backyard*).
- **🎬 Vertex AI Veo 3.1 3D Video Generation**: Uses Google's state-of-the-art **Veo 3.1 Image-to-Video** (`veo-3.1-fast-generate-001`) model to synthesize 3D spatial depth, steadycam forward dolly motion, and realistic volumetric lighting directly from 2D input photos.
- **🎙️ Cloud Text-to-Speech Tour Guide Narration**: Generates high-fidelity AI tour guide audio narration synchronized across all room scenes.
- **🎞️ Automated ffmpeg Video Assembly**: Automatically renders and stitches multi-room 3D video clips with the audio narration track into a single 1080p MP4 video tour.
- **☁️ Automated Public Cloud Storage Publishing**: Uploads final video packages to Google Cloud Storage with direct public access.
- **💻 Interactive ADK Web Interface**: Provides a rich interactive UI with video player components and A2UI card formatting.

## 🚀 Quickstart Guide

### 1. Prerequisites
- Python 3.10+
- `uv` package manager (`pip install uv`)
- `ffmpeg` installed on system path
- Google Cloud Project with Vertex AI and Text-to-Speech APIs enabled

### 2. Environment Setup
Clone the repository and install dependencies:
```bash
git clone https://github.com/Prithvi-Naidu/buildwithgemini-tour-agent.git
cd buildwithgemini-tour-agent
uv sync
```

Set environment variables:
```bash
export GOOGLE_CLOUD_PROJECT="your-gcp-project-id"
export GOOGLE_CLOUD_LOCATION="us-central1"
```

### 3. Launch Local Agent Web UI
Start the ADK Web server on port `8080`:
```bash
uv run adk web --port 8080
```
Navigate to `http://127.0.0.1:8080` in your browser to interact with the tour creation agent!
